# Shop Billing System

## How to Run This Project:
1. Make sure you have **Node.js** and **MongoDB** installed and running locally on your computer.
2. Open the terminal in this project folder and type `npm install` to download the backend dependencies.
3. Type `node server.js` to start the backend server.
4. Open a web browser and go to `http://localhost:3000`.
5. Login using the default credentials — Username: `admin` / Password: `password123`.
